# FaithOn - 창원교회 출석체크 관리 시스템

모바일과 PC에서 구역 임원 및 관리자가 간편하게 출석을 체크하고 통계를 파악할 수 있는 반응형 웹 애플리케이션입니다.

---

## 🚀 빠른 시작 (Quick Start)

Windows 환경에서는 `start.bat`을 더블 클릭하여 실행할 수 있습니다:

```bat
start.bat
```

또는 수동 실행:
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:3047` 로 접속합니다.
