# FaithOn 도메인 비즈니스 규칙 (Business Rules)

## 1. 최신 활성 연도(Active Year) 조회 규칙
- 주소록 관리자 대시보드의 **[서비스 활성 연도 적용]** 설정(`CWTB_SYSTEM_CONFIG` 테이블의 `ACTIVE_YEAR`)을 최우선 기준으로 사용합니다.
- 관리자가 활성 연도를 변경(예: 2026년 ➔ 2027년)하는 순간, 달력상의 날짜와 무관하게 시스템 전체(출석체크 명단, 구역 배정, 임원 권한 등)가 지정된 연도 체제로 즉시 전환됩니다.
- 설정값이 없을 경우 주소록 테이블(`CWTB_USER`)의 가장 최신 연도(`MAX(YEAR)`)를 fallback으로 사용합니다.
- 삭제(`DEL_YN = 'Y'`)되거나 숨김(`IS_HIDDEN = 'Y'`) 처리된 성도는 출석 목록 및 로그인 대상에서 제외됩니다.

---

## 2. 구역 임원 우선 정렬 규칙 (Roster Sort Order)
출석부 테이블은 출석 체크 편의를 위해 직책 우선순위로 정렬된 후, 일반 성도는 성명 가나다순으로 정렬됩니다:
1. **구역장** (1순위)
2. **부구역장** (2순위)
3. **조장** (3순위)
4. **조총무** (4순위)
5. **서기** (5순위)
6. **일반 성도** (가나다순)

---

## 3. 출석 일자 역산 규칙 (Date Resolution)
- **주일말씀 (Sunday)**: 오늘(Today) 이하의 날짜 중 일요일(요일값 0)인 가장 최근 4개 일자만 선택 가능.
- **수요말씀 (Wednesday)**: 오늘(Today) 이하의 날짜 중 수요일(요일값 3)인 가장 최근 4개 일자만 선택 가능.
- 미래 날짜는 선택 및 조회가 불가능합니다.

---

## 4. 대집회(7일 집회) 출석 및 정규 출석 자동 연동 / 수요일 자동 마감 규칙
- **수요일/주일 정규 출석 자동 동기화**: 7일간의 대집회 기간 중 수요일과 주일이 포함되어 있을 때, 대집회 탭에서 출석 체크(또는 체크 해제)를 진행하면 기존 구역 명단(정규 성도 및 정규 새참자)의 수요말씀(`wednesday`) 또는 주일말씀(`sunday`) 정규 출석부(`faithon_attendance`)에도 동일한 일자로 자동 동기화됩니다. (대집회 전용 새참자 `SNC_`는 기존 구역 명단에 없으므로 정규 출석부에서 제외).
- **정규 ➔ 대집회 양방향 동기화**: 활성 대집회 기간의 수요일/주일에 정규 출석 탭에서 체크/해제하는 경우에도 대집회 출석부(`faithon_special_attendance`)에 자동으로 상호 반영됩니다.
- **신규 대집회 시작일 도래 시 자동 활성화**: 사전에 새로운 7일간의 대집회를 미리 등록해두었거나 비활성(숨김) 상태였더라도, 해당 대집회의 시작일(`start_date`)이 도래하면 시스템이 자동으로 감지하여 `is_active = TRUE`로 활성화하고 출석체크 화면에 노출합니다.
- **종료 후 차주 수요일 자동 숨김(마감)**: 대집회 7일간의 집회가 끝난 후 도래하는 첫 번째 수요일 0시부터 지난 대집회 탭은 자동으로 숨김(비활성화 `is_active = FALSE`) 처리됩니다. 이후 수요일과 주일이 도래하면 기존 기준대로 정규 수요/주일 출석체크가 기본 화면으로 자동 활성화됩니다.
