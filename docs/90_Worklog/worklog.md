## [2026-09-09] 대집회 7일 집회 출석체크 정규(수요일/주일) 자동 동기화 및 종료 후 수요일 자동 숨김(마감) 체계 구현
- **대집회 ➔ 정규(수요/주일말씀) 자동 동기화**:
  - 7일간의 대집회 기간 중 수요일/주일 날짜에 대집회 출석 체크/해제 시 기존 구역 명단(정규 성도 및 정규 새참자)의 정규 출석부(`faithon_attendance`)에 동일한 일자로 자동 동시 반영.
  - 대집회 전용 새참자(`SNC_`로 등록된 `SPECIAL_NEW`)는 기존 구역 명단에 없으므로 정규 출석부 연동에서 자동 제외.
  - 정규 출석(수요/주일) 탭에서 체크/해제 시에도 활성 대집회 출석부에 동일하게 양방향 자동 동기화.
- **기존 출석 데이터(9/9 수요일) 초고속 일괄 소급 동기화**:
  - 금일(9/9) 대집회 출석자 182명 정규 수요출석부로 즉시 자동 소급 반영 완료.
  - 서버 기동 시 및 신규 대집회 생성/활성화 시 자동 소급 동기화 루틴 가동.
- **신규 대집회 시작일 도래 시 자동 활성화 (숨김 해제)**:
  - 사전에 미리 등록해두었거나 비활성(`is_active = FALSE`) 상태인 대집회라도, 시작일(`start_date`)이 도래하면 시스템이 실시간 감지하여 `is_active = TRUE`로 자동 활성화 및 구역 출석체크 화면에 자동 노출.
- **종료 후 차주 수요일 자동 숨김(마감) 및 정규 출석 자동 복원**:
  - 7일간의 대집회가 끝난(end_date) 후 도래하는 첫 번째 수요일 0시부터 지난 대집회 탭 자동 비활성화(`is_active = FALSE`) 및 숨김 처리.
  - 이후 수요일/주일 도래 시 기존 방식대로 정규 수요/주일 출석체크가 기본 화면으로 자동 활성화.
- **UI 시각적 피드백**:
  - `attend.html`: 대집회 일자가 수요일/주일일 때 "수요말씀 자동동기화" / "주일말씀 자동동기화" 안내 배지 실시간 표시.
